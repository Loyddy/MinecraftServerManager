# Minecraft Fabric Server Manager

A lightweight Minecraft Fabric server management panel built with Python Flask and Tailwind CSS. It supports one-click download and deployment of Fabric servers, real-time console command interaction, drag-and-drop Mod management, server performance monitoring, and automated world backups.

---

## 🛠️ Features

- **One-Click Deployment & Build**: Automatically fetches the official Fabric version list, downloads the `Fabric Installer` with a single click, automatically generates configurations, and agrees to the EULA.
- **Multi-Instance Management**: Independently manage multiple Fabric server instances with support for one-click start, stop, and deletion.
- **Dynamic Memory Configuration**: Easily modify the `-Xmx` / `-Xms` memory allocation limits online via a visual slider.
- **Real-Time Console**:
  - View server output logs in real time.
  - Send real-time console commands (e.g., `op`, `say`, `stop`, etc.) directly to the server.
- **Performance & Online Player Monitoring**: Track real-time server CPU usage, memory consumption (MB), and the online player list and count.
- **Mod Manager**:
  - Drag and drop or click to upload `.jar` mod files.
  - One-click enable/disable Mods (automatically renames files with `.disabled`).
- **Automated & Manual Backups**:
  - Manually archive and compress the `world` save with one click.
  - Background automated backups with a customizable global check interval.
  - Auto-cleanup mechanism: keeps only the 2 most recent backups per instance to prevent disk space exhaustion.

---

## 📋 Prerequisites

Before running this project, make sure your environment meets the following dependencies:

1. **Python 3.7+**
2. **Java Runtime Environment (JRE / JDK)**
   - Global `java` environment variables must be configured properly.
   - Prepare the matching Java version according to the Minecraft version you plan to deploy (e.g., **Java 17 / 21** is recommended for MC 1.20+).

## 🚀 Usage Tutorial

1. File Placement Directory

Before running the application, download the Assistant file0, make sure your project files are correctly organized in the following directory structure:

Root-Directory/(this file should be your server file)
│
├── Assistant/              # ⚙️ Assistant backend folder (where Python script and configurations reside)
│   ├── main.py              # 🚀 Backend main script
│   ├── config.json         # ⚙️ Configuration file
│   └── index.html          # 🎨 Frontend console page
│
├── Versions/               # 📦 Server instance root directory (dynamically generated)
└── backups/                # 💾 Backup root directory (dynamically generated)

At the begining you should only have Assistant and no Versions and backups, and these two files will be generated after the first time you successfully run main.py

2. 安装依赖库

把所有文件都放到指定位置了之后，打开main.py
然后在终端输入
pip install -r requirements.txt
等待安装完成之后
用你想用的方法运行main.py，几秒钟之后会自动弹出一个localhost，这个时候就可以正式开始部署你的服务器了

3. 开始运行

部署服务端：在页面上方的 “部署 Fabric 服务端” 模块中选择所需的 Minecraft 版本，点击 “一键下载 & 构建”[cite: 1]。
日常管理：构建完成后，即可在下方实例列表中进行启动、停止、分配内存、配置自动备份、查看实时控制台以及上传/管理 Mod[cite: 1]。
